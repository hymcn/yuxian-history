# 蔚县历史知识库

> 本库是公众号「**蔚县人的那些事**」的配套静态知识库，系统整理清光绪《蔚州志》（杨笃纂，1887）的校勘、译文与学术解读。

## 我们做什么

- **底本**：清光绪十三年（1887）庆之金修、杨笃纂《蔚州志》刻本影印
- **方法**：多智能体协同校勘、现代标点、全文译文、学术解读五段式
- **范围**：原书二十卷、三十三章、约二十五万字，已全部数字化译注
- **原则**：存真——不臆改原文，异体字照录、有疑必注

## 栏目

- **考据**：逐章地名、人物、军事、水利、物产专题
- **关于工程**：整理缘起与方法论

> <span class="seal">蔚县人的那些事</span>　读懂蔚州的每一页历史
