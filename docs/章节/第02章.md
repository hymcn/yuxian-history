# 第02章 纂修源流

### 例言

蔚州志现存的有三部：《志补》援引依据较为广博，《县志》取材于州志而加以详细补充，《州志》相传为敏果公（魏象枢）所起草，似乎并非魏公特意制定的体例。《志补》作者谦称不敢创新，其编排全部依照旧例，希望保存原书面貌，这是其慎重之处。如今将三部志书合为一部，必然难以完全遵循旧例，但也不愿对前贤著作轻率改动。于是另成一体，依照史书法式概括为四类：表、志、传、记。

表是纪年的体例，《新五代史》开始改变其形式，以"志"来记载地理，到皇朝舆地表，体制已经大为完备。现在仿照它编为舆地表，其次是历代封爵表以追溯创置沿革，其次是历代职官表以保存掌故，其次是本朝职官表，先记载设置、后记载裁撤裁缺，以重视现行制度。

志分为九类：地理志、建置志、祠祀志、赋役志、学校志、选举志、兵志、金石志、艺文志。将晷度、形胜、疆域、乡都、山川、关津、古迹、冢墓、物产各条目并入地理志；将城堡、公署、仓廒、驿递、镇集各条目并入建置志；其余篇目完全依照通志采访条款，体例完善，无须更改。

传即人物志，旧志分为乡贤、忠义、孝悌各类，但文体不同，整齐划一困难。引用古语入雅正文，既觉得不伦类；改古文从今体，又显得简陋。现在分为四类：采自正史及贤良祠传、满汉名臣传的为史传，录其全文；采自名人文集及家传、墓志、行状的为集传，节取其大意；其次是列传，记载各志及如今采访的事实；再其次是列女传，记载古代名媛及当今节孝贞烈的女性。

记有五类：大事记，创始于太史公（司马迁）；风土记，始于周处（字孝侯）；名宦记，旧时附在职官之后；寓贤记，旧时排列在人物之后。如今职官已成表，人物已成传，无法比附归类，所以归入记中。名宦记、寓贤记，名称因时而定。其他见于典籍的文献、出自异闻的事迹，无类可归的，汇辑于篇末，叫作杂记，这是通例。

全书共二十二篇，二十卷。卷首冠以图，图都用方格法绘制。总图一幅，以明确疆域；分图四幅，以详述村堡；渠道图，以记载水利；义仓图，以备荒政。那些描绘画景、界画楼台的图，与实际政务无关的，一概不登载。徇从俗例而破例的，只保存城池一图附于地利形胜部分，仍有可取之处。

书中正文都列出古籍原文，有考证订正的另为案语。凡是采自三部旧志的内容都加以注明，荟萃前人的精华，也就是保存前人的著作。

### 译注

1. **鑒定**：审定，由上级官员负责志书质量把关。王衮为宣化府知府，蔚州属宣化府管辖，故由知府鉴定。
2. **特用府**：清代知州的一种任用方式，指特别选用的府级知州。庆之金以举人身份被特用为蔚州知州。
3. **教諭**：县学长官，掌文庙祭祀和生员教导。杨笃时任新选繁峙县教谕（尚未赴任）。
4. **學正**：州学长官，从八品，掌州学教育。训导为副长官，佐学正/教谕管理学政。
5. **吏目**：州之佐杂官，从九品，协助知州处理文书事务。
6. **廩生**：府州县学中享受官府膳食津贴的生员，由学政考试选拔，名额有限。
7. **貢生**：从府州县学选送国子监（太学）深造的生员。分岁贡（定期选送）、恩贡（因恩诏选送）、附贡（附加名额）、增贡（增广名额）等类型。
8. **議敘州同**：因功绩议叙授予州同（知州副官）职衔，不一定实任。
9. **貤封**：因子孙功名而获封赠官阶，清制可上封一代。"貤封朝議大夫"即因子孙功名获封正五品文散官。
10. **廂藍旗**：即镶蓝旗，清代八旗之一。蔚州地区驻有八旗军，旗人通过教习制度参与文化教育。
11. **翰林院庶吉士**：翰林院储才，从新科进士中选拔，学习三年后散馆授职。
12. **敏果公**：即魏象枢（1617—1687），蔚州人，顺治三年进士，官至左都御史，谥敏果。清代名臣，相传曾起草顺治《蔚州志》。
13. **五代史始變其式**：指欧阳修《新五代史》改变表的体例，以志记载地理。实际上此处指方志中表体的演变。
14. **孝侯**：周处（238—299），字子隐，谥孝侯。著有《风土记》，为早期风土记代表作。
15. **開方**：地图绘制方法，即方格法（类似现代比例尺网格），以方格代表固定距离，是中国传统制图法。
16. **三志**：指顺治末年《蔚州志》、乾隆初年《蔚县志》、乾隆十年《蔚州志补》三部旧志。

## 三、学术解读

### 史源与编纂

本篇包含两部分内容——纂修姓氏和例言，二者共同构成光绪《蔚州志》的编纂文献。纂修姓氏记录了编纂团队的人员构成和分工体系，例言则阐述了全书的体例设计和方法论，是理解这部方志编纂理念的关键文献。

**编纂团队分析**：从纂修姓氏可以看出，光绪《蔚州志》的编纂团队采用"官修绅助"模式，分为五个层级：

1. **鉴定层**：宣化府知府王衮，代表上级官府的质量把关。
2. **纂辑层**：知州庆之金为总纂，杨笃为实际主编。杨笃是晚清著名方志学家，以考据严谨著称。
3. **参阅层**：学正戴问善、训导寇椿龄，代表地方学官系统参与审核。
4. **绅士层**：包括总理绅士3人、采访绅士17人，均为地方有功名的士绅，负责资料采集和协调。
5. **技术层**：督刊、缮写、绘图各1人，为工房书吏，负责出版技术工作。

团队成员中，科举出身者占多数：举人至少8人（庆之金、杨笃、戴问善、寇椿龄、刘徽典、刘彦魁、王袭、高善述、赵贵），翰林院庶吉士1人（贾联堂），各类贡生10余人。这一构成体现了清代方志编纂以士绅为核心的知识结构。

值得注意的是，镶蓝旗教习王袭的参与，说明蔚州地区满汉知识分子共同参与了地方志编纂，体现了清代畿辅地区满汉文化融合的特征。

### 制度史解读

**方志编纂的"表志传记"四体**：例言最重要的理论贡献是确立了"表志传记"四体框架。这一框架直接借鉴司马迁《史记》的纪传体史书体例，将方志编纂纳入史学规范：

- **表4篇**：舆地表、历代封爵表、历代职官表、本朝职官表——以表格形式记载行政区划、爵位、官制变迁
- **志9篇**：地理、建置、祠祀、赋役、学校、选举、兵、金石、艺文——以类目形式记载典章制度
- **传4篇**：史传、集传、列传、列女传——以人物传记形式记载历史人物
- **记5篇**：大事、风土、名宦、寓贤、杂记——以编年和杂录形式记载特殊事项

这一分类比传统方志更为精细。特别是将"金石志"独立设类，体现了清代金石学兴起对方志编纂的影响；将"传"细分为史传（录自正史）、集传（录自文集）、列传（采访事实）、列女传四类，解决了旧志人物分类混乱的问题。

**三志合并的方法论**：例言提出"合三志为一"的编纂策略，同时强调"不欲於前賢著作輕竄易"，体现了继承与创新的平衡。具体方法为"凡採之三志者並爲註明"——明确标注资料来源，既荟萃前人精华，又保存前人著作。这一方法在清代方志编纂中具有典范意义。

### 学术史解读

**乾嘉学风的影响**：例言中"準史法""別爲案語""徵信""考訂"等表述，体现了乾嘉考据学派对晚清方志编纂的深刻影响。杨笃作为主编，其考据学风直接决定了志书的学术品质。将旧志分类重新整合，不轻改前人原文而以案语形式出校，正是乾嘉学术"实事求是"原则在方志领域的实践。

## 四、背景知识

### 清代方志编纂制度

清代是中国方志编纂的鼎盛时期。清廷多次下诏修志，形成从一统志到通志到府州县志的完整层级体系。方志编纂一般采用"官修绅助"模式：由地方官主持（知州/知县为总纂），延请文人学者实际编修，地方士绅参与资料采集。光绪《蔚州志》正是这一模式的典型实践。

### 清代科举与贡生制度

纂修姓氏中出现的多种功名，反映了清代科举制度的层次结构：

- **进士**：殿试中式，分三甲。赐进士出身为二甲。
- **举人**：乡试中式，有做官资格。
- **翰林院庶吉士**：从新科进士中选拔的储才。
- **贡生**：从府州县学选送国子监的生员，分岁贡、恩贡、拔贡、副贡、优贡等。
- **廪生/增生/附生**：府州县学的生员等次，廪生享受官府津贴，增生名额次于廪生，附生为附学生员。

### 八旗制度与畿辅驻防

蔚州地处京师西北，属畿辅地区，清代驻有八旗军队。镶蓝旗为下五旗之一。旗人设教习管理文化教育，王袭以镶蓝旗教习身份参与方志编纂，体现了满汉知识分子在地方文化建设中的合作。

### 知识卡片

- **楊篤（1824—1902）**：字秋湄，山西乡宁人。同治甲子科（1864年）举人。晚清著名方志学家，先后纂修《蔚州志》《代州志》《西宁县志》《长子县志》等多部方志，以考据严谨、体例精善著称。在光绪《蔚州志》中任实际主编，"公餘輒就商訂，閱五月書成"。
- **魏象枢（1617—1687）**：字环极，蔚州人。顺治三年（1646）进士，官至左都御史、刑部尚书。清代名臣，以直言敢谏著称，谥"敏果"。相传曾起草顺治《蔚州志》，故例言称"州志相傳爲敏果公筆"。
- **王育榞**：字石浦，山西猗氏人。雍正丁未进士，蔚县知县。修《蔚州志补》十一卷（乾隆十年，1745年），即例言所称"志補"。
- **表志傳記**：纪传体史书的四大体例，源于司马迁《史记》。光绪《蔚州志》将此四体移植于方志，形成"表四、志九、传四、记五"的完整结构，全书22篇20卷。
- **開方制圖**：中国传统地图绘制方法，以方格代表固定距离（如每方十里），类似现代比例尺网格。光绪《蔚州志》图谱即采用此法，"右每方十里"。
- **三志**：指顺治末年李英修《蔚州志》、乾隆初年《蔚县志》、乾隆十年王育榞修《蔚州志补》。光绪志将三志合为一书，"萃前人之精，卽以存前人之書"。
