# 第17章 兵志

> 据光绪《蔚州志》第17章（校勘 + 译文 + 学术解读）。完整校勘、影印对照与全集见公众号「蔚县人的那些事」。

### 蔚州路辖域

蔚州路管辖东城、西城、黑石岭、桃花堡、四营堡等处。据《畿辅通志》，原辖广昌城，于雍正六年改隶大同本路。

### 蔚州路都司

设都司一员。据营册，原设南路参将一员，驻扎西城。顺治十年移驻蔚州，改蔚州卫都指挥为中军守备，隶属于参将。嘉庆十六年，参将移驻八沟，改设都司、守备一员，裁撤把总一员、额外外委一员。

马步守兵编制变迁：营册原额兵四百名。自顺治十年至康熙三十六年，陆续抽调裁汰及缺额未补者共二百五十名。雍正十二年添设马步兵九十名。乾隆年间陆续裁扣马步守兵七十名，四十八年恢复额设马兵一名、守兵五名。嘉庆十九年裁步兵三名。道光元年至二十二年陆续裁拨马步守兵二十二名。现设兵一百二十五名，其中马兵二十五名、步兵二十名、守兵八十名。

经费：每年支放官俸、兵饷、马乾等银二千七百八十二两一钱九分六厘，本色米四百四十八石八斗。

马匹：营册原额马一百二十匹。康熙年间裁汰马三十八匹，拨归驿站马五十匹。雍正十二年添营马三十六匹。乾隆年间陆续裁汰营马三十二匹，四十八年恢复额设营马一匹。各官自备马十四匹，嘉庆十六年裁自备马八匹。道光年间陆续裁营马六匹。

随营军器：据志补，堪用大小炮共四千五百一十四位，子母炮二位。藤牌二十三面，铃铛六十四个。堪用盔甲二百六十副，弓四十七张，虎衣二十三身。鸟铳八十四杆，撒袋四十七副，腰刀七十四口，锣锅九口，帐房十顶。旗帜四堂，官兵战箭三千五百一十枝。每三年更换新火药一千九百三十斤八两。

### 东城营

地属西宁县（即今西宁县治）。设千总一员。营册原设守备，咸丰十年改千总。设经制外委一员。辖马步守兵。

兵额变迁：营册顺治年间原额兵二百名。康熙年间陆续调拨裁汰及缺额未补兵一百六十名，实存兵四十名。雍正十二年添设马步兵六十名，此后陆续裁去五十九名。现设兵四十三名，其中马兵十二名、步兵十一名、守兵二十名。

经费：每年支放官俸兵饷马乾等银一千零七十八两，本色米一百五十石五斗。

马匹：官自备马四匹，营马十二匹。原设营备马六十匹，历年裁存。军器：大小铁炮一千九百四十八位，子母炮一位。鸟铳三十五杆，腰刀七十五口，钺斧三十五把，牌刀十七面口。马步守兵盔甲八十四副，虎衣十四身，弓三十张，战箭一千六百八十枝，帐房三架，旗帜三堂。储备铅二百二十九斤，储备火药七百七十四斤。

### 西城营

即今西宁县治（今山西省广灵县）。设把总一员。营册参将移驻后设守备，雍正十年改都司，嘉庆十八年改把总。辖马步守兵。

兵额变迁：营册康熙十一年原额兵二百名。三十二年陆续裁汰及缺额未补兵一百五十八名，实存兵四十二名。雍正十二年添设马兵五十八名。嘉庆十六年裁存四十八名，道光二十二年复裁十一名。现设兵三十七名，其中马兵十一名、步兵九名、守兵十八名。

经费：每年支放官俸兵饷马乾等银七百八十九两，本色米一百三十石。

马匹：官自备马二匹，营马八匹。原设营备马七十匹，历年裁存。军器：大小炮一千二百四十位，子母炮一位。鸟铳三十杆，四眼铳六杆，三眼铳一百十一杆，一眼铳一百三十六杆，百子铳三杆。双头枪五杆，折腰枪六杆，燥鞭枪一杆，快枪七杆，夹靶枪六杆，长枪十一杆。钺斧三十四把，腰刀六十四口，斩马刀二十八口，豆角刀二十三口，牌刀十六面口。弓三十张，战箭一千六百枝，撒袋三十副。马兵盔甲二十六副，步兵盔甲二十四副，守兵盔甲三十四副。虎衣十身，旗帜一堂，帐房四架。锣锅二口，储备火药八百一十五斤，储备铅二百二十五斤。

### 黑石岭堡

设经制外委千总一员。原设把总，道光十二年改外委。辖马守兵。

兵额变迁：顺治年间原额兵五十名。陆续裁汰调拨至乾隆四十八年，裁存兵二十二名。道光年间复裁八名。现设马兵一名（道光二十二年从蔚州营移驻马兵一名），守兵十四名。

经费：每年支放兵饷马乾等银二百二十八两，本色米五十石四斗。

马匹：营马一匹。军器：灭寇炮七位，石炮一百六十四位。鸟铳十一杆，三眼铳十三杆，长枪二杆。战箭三百七十枝，铁斧十二把，盔甲二十八副。旗帜一堂，帐房二架，锣锅二口。储备铅子五十斤，储备火药二百八斤。

### 桃花堡

设经制外委把总一员。营册原设把总，嘉庆十六年改设经制外委。辖马守兵。

兵额变迁：营册顺治八年原额兵八十名。九年裁汰兵三十名，十八年裁拨兵三十三名。康熙二十三年复额，实存四十名。此后陆续裁拨二十七名。现设马兵一名（道光二十二年从西城营移驻），守兵十三名。

经费：每年支放兵饷马乾等银二百八两八钱，本色米五十石四斗。

马匹：营马一匹。军器：大小炮五百五十三位。鸟铳十杆，长枪三十五杆。钺斧十把，腰刀二口，牌刀三面口。战箭八十枝，盔甲二十四副，虎衣三身。旗帜二堂，帐房一架。铁子二千七百个，又铁子二十斤。储备铅四十五斤，储备火药二百八斤。

### 防汛

（东城、西城不载。）

东路汛设六处：大德庄汛、西合营汛、吉家庄汛、红桥儿汛、甯远店汛、鴉涧堡汛。每汛各设守兵二名。其中甯远店、鴉涧堡二汛属桃花堡营。

西路汛设二处：暖泉堡汛、五岔岭汛。每汛各设守兵二名。

南路汛设四处：神通沟汛、潮淘口汛、明铺汛、仙人桥汛。每汛各设守兵二名。其中潮淘口三汛属黑石岭营。

北路汛设五处：梁家庄汛、西辛店汛、袁家竈汛、东辛店汛、北水泉汛。每汛各设守兵二名。

### 校场与军庄

校场在东关外，占地六十亩。

军庄：东关外校场余地四顷五十二亩，辛家庄咸滩河济地一十一顷，南山马灼菴山坡地三顷二十亩。

### 译注：6条

1. **都司**：清代绿营武官，正四品，位次参将、游击。蔚州路原设参将（正三品），嘉庆十六年降格为都司，反映了蔚州军事地位在清中叶的下降。
2. **马步守兵**：绿营兵分三类：马兵（骑兵）、步兵（战兵）、守兵（守城铺兵）。马兵待遇最高，守兵最低。蔚州路现设一百二十五名中，守兵八十名占六成以上，说明其职能以地方守备为主。
3. **马乾**：即马乾银，清代绿营马兵、军官养马之津贴。每年按马匹数支放银两，供购买草料之用。裁马即裁马乾，是裁兵节饷的重要手段。
4. **本色米**：清代兵饷有银、米两项。本色米即以实物粮食支放，折色则折银。蔚州路岁支本色米四百四十八石八斗，按一百二十五名兵计，人均约三石六斗。
5. **经制外委**：清代绿营低级武官。经制外委为正式编制外委，额外外委为临时编制。把总、千总之下设外委，分防汛地。
6. **子母礮**：明代发明之小型火炮，母炮发射子炮（预装火药铁弹之炮管），可轮流装填，提高射速。清代绿营广泛装备，蔚州各营均有配备。

## 三、学术解读

### 史源与编纂

蔚州兵志的编纂以"营册"为主要史源，辅以《畿辅通志》《西宁县志》及"志补"。志文凡引营册者皆注明"营册原设""营册原额"，引方志者注明"畿辅通志""西宁县志"，引前志者注明"志补"，体例严谨。全篇以"营—堡—汛"三级编制为纲，每级下分"营制—兵—经费—马匹—军器"五目，条理分明，是清代方志兵志门类的标准格式。

"现设兵"一项是全篇的关键——它不是某一年的静态数字，而是从顺治原额经康熙、雍正、乾隆、嘉庆、道光各朝裁汰添设后的净结果。编者将每一轮裁添的数字逐条列出，最后合计为"现设"，使读者可以追溯兵额变迁的全过程。这种"编年式裁添记录法"是清代绿营兵志的特色体例。

### 军事制度解读

**卫所改营的过渡**：蔚州路都司的沿革清晰展现了明清军事制度转换的轨迹。明蔚州卫设都指挥使，顺治十年"改蔚州卫都指挥为中军守备隶之"，标志着卫所武官向绿营体制的过渡。嘉庆十六年参将移驻八沟、改设都司，则是绿营编制内部级别的调整——从参将（正三品）降为都司（正四品），反映了蔚州在清中叶军事地位的下降。这一变迁与蔚州从边塞重镇向内地州县的行政转型相一致。

**兵额裁减的趋势**：蔚州路兵额从顺治间原额四百名，经康熙朝裁汰二百五十名（裁去六成以上），雍正十二年添设九十名（回补），乾隆至道光间又陆续裁减，最终现设一百二十五名，仅为原额的三分之一弱。东城营从二百名裁至四十三名，西城营从二百名裁至三十七名，黑石岭堡从五十名裁至十五名，桃花堡从八十名裁至十四名。这一持续两百年的裁兵趋势，反映了清代边防压力的减轻和财政紧缩的政策取向。

**防汛体系的空间格局**：四路十七处汛防构成了蔚州路守备的空间网络。东路六汛沿壶流河通往宣府方向分布，西路二汛通向大同方向，南路四汛扼飞狐口通道，北路五汛沿边境线分布。每汛仅设守兵二名，说明这些汛防的功能以传递信息、维持治安为主，而非实战防御。这种"铺递式防汛"是清代内地绿营的典型形态。

### 军器装备解读

蔚州各营军器清单完整记录了清代边镇绿营的武器装备体系。火器方面，大小礮（炮）是主力重武器，蔚州路本营有四千五百一十四位，东城营一千九百四十八位，西城营一千二百四十位。鸟铳（火绳枪）是单兵主要火器。三眼铳、四眼铳等多为本地铸造之杂式火铳。冷兵器方面，长枪、斩马刀、腰刀、牌刀构成近战武器体系。防御装备有盔甲、藤牌、虎衣（惊吓敌马之用）。储备物资有火药、铅子、铁子、帐房等。"三年出陈易新火药"制度保证了火药的定期更新，是防止火药受潮失效的重要措施。

## 四、背景知识

### 地理背景

蔚州地处恒山山脉北麓，飞狐口为南北交通咽喉，自古为宣大边防体系之要地。州治在壶流河畔，东通宣府，西连大同，南扼飞狐口，北接塞外。蔚州路辖东城（今河北阳原西城镇一带）、西城（今山西广灵）、黑石岭（蔚县与涞源交界）、桃花堡（蔚县东部）等处，构成以蔚州城为中心的扇形防御体系。黑石岭堡在城南七十里，扼飞狐陉之北口，为蔚州南面屏障；桃花堡在城东，控壶流河通往宣府之路。

### 历史背景

**明蔚州卫**：明代蔚州设卫，属万全都司管辖，是宣府镇防体系之重要一环。蔚州卫指挥使以下世袭武官二十四家，构成了蔚州社会最核心的武官阶层（详见选举志卫所世职部分）。明末蔚州卫军事功能渐衰，卫所制度名存实亡。

**清初卫所改营**：清顺治十年（1653），将蔚州卫都指挥改为中军守备，纳入绿营编制，隶属南路参将（驻西城）。这一改革标志着蔚州从卫所制向绿营制的过渡。雍正六年（1728）广昌城改隶大同，蔚州路辖域缩小。

**嘉庆降格**：嘉庆十六年（1811），参将移驻八沟（今河北平泉），蔚州路改设都司。参将为正三品，都司为正四品，级别降低，反映蔚州在清中叶已从边防前沿转变为内地州县，军事地位下降。

**持续裁兵**：从顺治到道光近二百年间，蔚州各营兵额持续下降。蔚州路从四百名裁至一百二十五名，四营堡合计从五百三十名裁至一百零九名。这一趋势与清代全国绿营裁兵的大背景一致——康熙朝因三藩之战后大规模裁军，乾隆朝因财政紧缩继续裁减，道光朝因鸦片战争后军费压力进一步裁兵。

### 制度背景

**绿营编制**：清代绿营以"镇—协—营—汛"为编制层级。蔚州路属宣化镇管辖，设都司（营级），下辖东城营（千总）、西城营（把总）、黑石岭堡（外委千总）、桃花堡（外委把总）。营下设汛，每汛设守兵二名，由把总或外委管辖。

**马步守兵制**：绿营兵分马兵、步兵（战兵）、守兵三类。马兵配马，负责侦察、追击；步兵为战兵，负责野战；守兵负责城守、铺防。三者在饷银上有别：马兵月饷二两，步兵一两五钱，守兵一两。蔚州路守兵八十名占六成以上，说明其职能以地方守备为主。

**军庄制度**：军庄是绿营的屯田土地。校场余地、咸滩河济地、山坡地等军庄土地的产出，用于补贴军费。蔚州军庄总面积近十九顷（约一百九十亩），规模不大，说明蔚州绿营的军屯并不发达，主要经费仍依赖财政拨饷。

### 知识卡片

- **绿营**：清代国家常备军之一，以绿旗为标志，由汉人组成，区别于满蒙八旗。绿营以省为建制，归总督、巡抚节制。蔚州路绿营属宣化镇管辖。
- **参将**：清代绿营武官，正三品，位次副将，统辖一营或一路。蔚州路原设参将，嘉庆十六年降格为都司。
- **都司**：清代绿营武官，正四品，位次游击。蔚州路嘉庆十六年由参将改为都司，级别降低一级。
- **千总·把总·外委**：绿营中下级武官。千总正六品，把总正七品，外委（经制外委、额外外委）更低。蔚州各营堡分别由千总、把总、外委统辖。
- **防汛**：清代绿营在交通要道、关隘渡口设置的哨所，每汛设守兵二名，负责传递信息、巡查治安。蔚州四路十七汛构成铺递式防御网络。
- **马乾银**：清代绿营马兵、军官之养马津贴。每年按马匹数支放银两，供购买草料。裁马即裁马乾，是裁兵节饷之重要手段。
- **子母礮**：明代发明之小型火炮，由母炮和预装之子炮组成，可轮流装填发射，提高射速。清代绿营广泛装备，蔚州各营均有。
- **虎衣**：绿营兵卒所穿虎纹衣甲，作战时穿着以惊吓敌马。蔚州路有虎衣二十三身，黑石岭堡、桃花堡亦有配备。
