# 第16章 学校志

> 据光绪《蔚州志》第16章（校勘 + 译文 + 学术解读）。完整校勘、影印对照与全集见公众号「蔚县人的那些事」。

### 文庙修建沿革

蔚州文庙位于州署之北，始建于元代至元年间。明代天顺年间知州史魁修葺，宏治年间知州姜鄗修葺，万历年间知州熊明誠及洪有声先后修葺，崇祯年间知州陈鹏举修葺。文庙建制为：正殿五间，东西廊庑各九间，碑亭二间，戟门三间，泮池桥坊二座，灵星门三间。门外牌坊有"泮述六经坊""垂宪万世坊"各一座。

明末卫人抚宁侯朱永曾捐资修文庙。清顺治间知州曹士琦重修。州人魏象枢撰碑记，大意如下：

"文风的盛衰系于庙学的兴废。蔚州地处三晋边塞，文风鼎盛之时，无论德行、气节、经世之才、文章之学乃至理学通儒，载于郡志者代不乏人。明末学宫倾颓，士气压抑，科举中断达十八年之久。州侯陈鹏举公拓修明伦堂，设立社学考校文章，科第方才恢复。"

碑记又云："来者相互劝勉，进入学宫，接受教诲而心生愉悦，如云蒸霞蔚，奋发兴起，以备一日之用，便能与蔚州先辈诸君子接踵比肩，又有何逊色？况且近年科第联翩，前后辉映。州侯每月有课考，每季有考试，教导劝勉之法无微不至。蔚州为极边之地，若论人杰则地灵，亦非堪舆家的荒唐之说。综观壬午以前、甲申以后的盛衰兴废之理，都有实据可验，在人耳目之间。我侯借此以副天子释菜之大典，不仅是寻常的文饰虚文而已。诸生当善体州侯之意！"

曹公名士琦，字韩伯，守蔚州将近一年，清廉方正不阿，爱民多有惠政，此处不一一详述。

自康熙以降，文庙历经十数次重修。康熙间知州耿夔忠、蔚县知县郭允文并修；卫人杨变春、李云华、聂源等先后捐修，县人袁兆图、李昌龄捐修门墙栅栏。雍正十一年知州李培仁、知县王育榞再修改建，崇圣祠规制至此完备。乾隆二十二年裁并蔚县，于文庙西设蔚乡学，春秋祭祀与州学共之。曾议另建文庙未成，春秋仍于州庙行祭，每祭州学先行、乡学次行。康熙三十二年改县设教谕时，乡贤李振藻捐银五百两。

按：蔚州卫自明代不设学校，应试者皆附州学及都司学。学正、训导署原在庙西，县教谕署在县署南。裁并后设乡学，即以州学训导兼任，遂移学正署于庙东，以学正旧署为乡学。此后乾隆三十九年知州靳荣藩、四十五年知州王建中、嘉庆十七年知州胡逊、道光九年知州包骙、咸丰六年署知州陆慎言、同治九年知州李秉衡，先后重修。

### 崇圣祠与愿学堂

崇圣祠在明伦堂后。据志补记载，康熙元年大司寇魏敏果公（魏象枢）于崇圣祠之东建愿学堂，作为讲学之所。据《寒松堂年谱》，知州郑牧民捐俸建寒松堂于明伦堂西。乾隆五年，训导辽阳州人高登第及绅士各捐资重修——大门一间、门房二间、讲堂三间、茶房一间。又前志载省牲亭三间，久已坍毁，后康熙五十年邑人训导张偀重建。崇圣祠神牌久损，知州为之重置奉祀。

### 祭器与乐器

蔚州文庙拥有完整的礼器体系：锡爵一百三十三只，锡登二件，锡铏原八件（雍正四年增），簋原五十六件增后共七十六件，簠原六十四件增后共七十六件，笾原一百二十件增后共一百八十件，豆原一百二十件增后共一百八十件，另有木碟、西杯、宫碗、汤碗、资碟、帛匣、铁燎炉等。康熙五十一年，州学生张□、陈纶、马毓秀、马启沆整饬祭器，存册在学。乐器涵盖钟、鼓、磬、琴、瑟、笙、箫、笛、埙、篪、籥、翟等二十余种，构成完整的"八音"之制。

### 文庙六章乐章

此志完整收录清初颁行的文庙祭祀乐章六章，依次为：迎神奏咸平之章，初献奏甯平之章，亚献奏安平之章，终献奏景平之章，彻馔奏咸平之章，送神奏咸平之章。志案指出，尚书李周望《国朝礼乐录》成书于康熙间，自乾隆九年新颁乐章、十八年议定祀位后，书中所载乐舞谱已与《大清通礼》不合；道光以来增祀诸贤，更无从知晓。然地方仍有沿袭旧章未改者，不可不厘正。故此志特载同治二年所颁祀位四图，并祭器、乐器、乐章，与李书及各志参稽。

### 学宫藏书

学宫收藏明代洪武、永乐、崇祯三朝及清代康熙至乾隆间颁赐书籍二十余种，包括《为善阴骘》《孝顺事实》（洪武十年颁），《五经大全》《四书大全》《性理大全》（永乐十年颁），《孝经》《小学》（崇祯六年颁），《孝经衍义》（康熙三十五年颁），《圣谕广训》（雍正二年颁），《名教罪人》诗（雍正四年颁），《御纂周易折衷》及诸经传说汇纂、《钦定四书文》（乾隆六年颁）等，兼有上谕、则例、《学政全书》《畿辅通志》等，是研究清代地方官学藏书制度的珍贵资料。

### 州学与乡学学额

州学设廪膳生员三十名，每二年一贡；增广生员三十名。科试取进童生：文童十八名，武童十五名。乡学设廪膳生员二十名，三年一贡；增广生员二十名。科试取进童生亦为文童十八名、武童十五名。入额定例从顺治九年分大学、中学、小学，至雍正二年蔚州、蔚县改大学各取十名，武童岁试取十五名，屡有增减。

### 书院与义学

蔚州书院义学共五处。会文义塾在儒学东，原为旧文场考棚，旧志载有蔚萝书院在巡道署东，顺治三年建，后巡道裁废，今义塾即旧志之考棚。康熙五十五年知州冯敬玉重修文场，碑记云"蔚萝旧有书院，凡岁科试并灵广四学生童俱得就近考试"，所言灵广四学指灵邱、广昌、广灵等地。读书林在州署南，康熙九年知州佟湘年建，后历经重修，有经费地一顷五十八亩。乡义学在东街，旧名蔚萝书院，乾隆四年候补主事李舜臣建，有经费地及生息本钱一千五百千。暖泉书院在州西三十里，元代创建。文蔚书院在东街，乾隆四十年知州靳荣藩建，州人李源撰碑记。

### 文蔚书院纪略

靳荣藩《书院纪略》序云：到蔚州第二年，地方绅士以创建书院之议相请。他认为此事不可轻言，国家培植人才，若有出众之资，不必虑其伏于涧底。塞上风霜多，处处无竹，又少梅花，几欲叹空谷。松树在其间，岁寒犹有余馥，愿如树木之人，各因其材而笃。又论及书院管理之弊：省府州县多有以书院为长吏馆舍者，饰厨传、立驿舍，广居邃宇半属邮亭，客去而马牛溲溺，不堪闻问。山长一席，近世荐牍纷如，往往私其知旧，上官迁而他往，山长亦去而不顾。建议买田庐而散收其息，遴儒生而专责其成，每岁更迭相代，前后交核，不使吏胥经涉其间，防微杜渐。诸生肄业者，庠师试而后闻诸州，州再试而择其可，则两蔚人文当复见四十年以前之盛。越半载而书院成，又两载而纪略锓版。

### 译注：6条

1. **释菜之典**：古代入学时以芹藻等菜蔬祭祀先圣先师之礼。《礼记·学记》"大学始教，皮弁祭菜"，郑玄注"祭菜，礼先圣先师也"。魏象枢碑记以此典故勉励诸生。
2. **魏敏果公**：魏象枢（1617—1687），蔚州人，清初理学名臣，官至刑部尚书、左都御史，谥敏果。雍正间入祀贤良祠。所建愿学堂为蔚州理学教育之重要场所。
3. **廪膳生员**：明清时期享受国家廪米津贴之生员，简称廪生。州学额设三十名，每二年可向国子监贡送一人。增广生员（增生）不享廪米，但可参加科考。
4. **灵广四学**：指蔚州周边灵邱、广昌、广灵等地之州县学。蔚萝书院使这些地方的生童可就近参加岁科考试，免跋涉云中之劳。
5. **山长**：书院之主持人，掌教学及院务。元代《元史》以山长为除目（正式任命之官职），清代则多由地方官延聘，地位渐趋复杂。
6. **靳荣藩**：乾隆间知蔚州，多次主持蔚州公共工程，建文蔚书院为其重要政绩。其《书院纪略》详细论述了书院经费管理之弊端与改革建议。

## 三、学术解读

### 史源与编纂

蔚州学校志的编纂具有鲜明的"层累"特征。文庙修建沿革从元代至元年间建庙起，历明清两代十数次重修，每一任知州的修葺记录均逐条列出，形成完整的修缮谱系。这一体例继承了方志"建置志"的传统，但将学校建筑与祭祀、藏书、学额、书院等作为一个有机整体编排，体现了清代方志对"学校"门类的系统化处理。

志案部分尤具学术价值。编者明确指出李周望《国朝礼乐录》成书于康熙间，此后乾隆九年新颁乐章、十八年议定祀位、道光以来增祀诸贤，书中所载已与《大清通礼》不合，"然至今犹或相承未改，是不可不厘正者"。这种以当代制度校正前人著述的编纂意识，超越了简单的资料汇编，具有学术考证的自觉。

学宫书籍一栏以"今缺依志补载"为注，说明原书已散佚，编者据前志追录，体现了存真的文献态度。文蔚书院纪略序文虽原刻漫漶甚重，仍据残存笔画推补录入，并保留不可辨识之处以□标示，符合"有疑必注"的原则。

### 学校制度解读

此篇完整呈现了清代蔚州官学体系的三个层面：

**建筑层面**：文庙（祭祀）→ 明伦堂（讲学，左右进德、修业二斋）→ 崇圣祠（祭祀孔子五代祖先）→ 愿学堂（理学讲学）→ 圣制楼（藏御制石碑）→ 专经阁（藏书）→ 奎星阁（风水建筑），构成完整的学宫格局。这些建筑的功能分区清晰：祭祀区（文庙、崇圣祠）、教学区（明伦堂、斋舍）、藏书区（专经阁、圣制楼）、辅助区（省牲亭、茶房），反映了清代官学"庙学合一"的制度特征。

**学额层面**：州学廪生三十名、增生三十名，每二年一贡；乡学廪生二十名、增生二十名，三年一贡。入额定例从顺治九年（大学四十名、中学三十名、小学二十名）到雍正二年（蔚州、蔚县改大学各取十名），反映了清初学额制度从"大中小三级制"向"府州县定制"的演变。乡试额中从顺治二年宣属旦字号中三名，到雍正十二年因添入蔚州而增中至四名（照奉天府夹字号额），再到嘉庆十二年裁改中顺天通州，则体现了清代乡试解额制度与行政区划调整的联动关系。

**书院层面**：蔚州书院从元代暖泉书院、明末蔚萝书院，到清乾隆间文蔚书院，形成三个发展层次。文蔚书院的经费结构尤为完整：田地十六顷十五亩（收租米谷）、房屋二十一处（收房租钱）、生息本钱九千七百千（收利息），构成田租、房租、息金三项收入来源。靳荣藩在序中提出的"买田庐而散收其息""遴儒生而专责其成""每岁更迭相代""前后交核"等管理原则，是清代书院经费制度从捐纳制向基金制转型的典型表述。

### 礼乐制度解读

志案关于乐章沿革的说明揭示了清代礼制改革在地方执行中的滞后性。康熙朝颁行的"咸平、甯平、安平、景平"六章乐章，至乾隆九年已有新颁乐章（改"平"为"章"字结尾），但蔚州仍沿旧制。祭器数字中多次出现"雍正四年增""雍正十年增""雍正十二年增"，反映雍正朝对文庙祭祀规格的系统调整。这一组数据为研究清代释奠礼的器物制度变迁提供了精确的时序坐标。

### 魏象枢与蔚州理学

愿学堂的建立是清初蔚州理学兴盛的重要标志。魏象枢作为清初理学名臣，在蔚州倡导"躬行实践"的学风，愿学堂即其实践基地。碑记中"云蒸霞蔚，奋然而兴""释菜之盛典"等语，将文庙修缮与科举复兴、人才培养直接关联，体现了"庙学兴则文运盛"的儒家教育理念。此后蔚州学风的传承，与魏象枢的影响有直接关系。

## 四、背景知识

### 地理背景

蔚州地处恒山山脉北麓，飞狐口为南北交通咽喉，自古为边塞军事重镇。州治在壶流河畔，城周山峦环合，故靳荣藩试士诗有"一城环绕万山中"之句。州西三十里有暖泉，水热不冰，元代于此建暖泉书院，为蔚州最早的书院。州署北为文庙所在，明伦堂后为崇圣祠，崇圣祠东为愿学堂，构成蔚州学宫的核心区域。

### 制度背景

**文庙祭祀体系**：至圣先师孔子正中南面，四配为颜回、曾参、孔伋、孟轲，十二哲列东西，东西庑从祀先贤先儒。崇圣祠祀孔子五代祖先：肇圣王木金父、诒圣王防叔、裕圣王祈父、昌圣王伯夏、启圣王叔梁纥。每岁春秋仲月上丁日行释奠礼，故乐章有"春秋上丁"之句。

**清代文庙乐章沿革**：顺治十三年首颁文庙乐章；康熙间重修（即此志所载版本，各章以"平"字为名）；乾隆九年新颁乐章（改"平"为"章"字结尾）；同治二年调整祀位（增祀先儒）。志案所辨"至今犹或相承未改"，正是地方沿用康熙旧章而未从乾隆新制的实证。

**书院经费制度**：清代书院经费来源主要有三：田租（学田）、房租（铺面房屋）、息金（生息本钱）。靳荣藩提出的管理改革——"买田庐而散收其息""每岁更迭相代""前后交核而不使吏胥经涉"——反映了清代中叶书院管理从官办向官督绅办转型的制度探索。

### 人物背景

- **魏象枢**（1617—1687）：字环极，号寒松，蔚州人。清顺治三年进士，历官至刑部尚书、左都御史，谥敏果。雍正间入祀贤良祠。为清初理学名臣，以直言敢谏著称。康熙元年建愿学堂于蔚州，倡导躬行实践之学。著有《寒松堂集》。
- **曹士琦**：字韩伯，顺治间知蔚州，清廉爱民，重修文庙，魏象枢为之撰碑记。
- **靳荣藩**：乾隆间知蔚州，三十九年重修文庙，四十年建文蔚书院，撰《书院纪略》详论书院管理。其试士诗"灵气独钟恒岳北"句，寄望蔚州人文复兴。
- **李周望**：蔚州人，官至礼部尚书，著有《国朝礼乐录》，为康熙间所辑清代礼乐制度之要籍。
- **李振藻**：蔚州乡贤，康熙三十二年捐银五百两修文庙。
- **冯敬玉**：康熙五十五年知蔚州，重修文场，碑记述蔚萝书院历史。
- **佟湘年**：康熙九年知蔚州，建读书林于州署南。

### 知识卡片

- **愿学堂**：魏象枢于康熙元年（1662）建于蔚州文庙崇圣祠东，是清初蔚州理学讲学之所。体现了清初理学与地方教育的结合，是研究清初北方理学传播的重要个案。
- **释菜礼**：古代入学时以苹蘩之菜祭祀先圣先师之礼，不用牲牢。《礼记·学记》"大学始教，皮弁祭菜"。魏象枢碑记以此典故勉励诸生，将文庙修缮与科举复兴直接关联。
- **咸平、甯平、安平、景平**：清代文庙乐章各章之"平"字，象征"太平"之意。乾隆以后改为以"章"字结尾。志案特辨正旧章与新制之异，是研究清代礼乐制度地方执行的典型案例。
- **八音**：古代乐器按材质分为金、石、土、革、丝、木、匏、竹八类。蔚州文庙乐器涵盖钟（金）、磬（石）、埙（土）、鼓（革）、琴瑟（丝）、柷敔（木）、笙（匏）、箫笛篪籥（竹），完整具备八音之制。
- **廪膳生员**：明清州县学中享受国家廪米津贴之生员，简称廪生。蔚州学额设廪生三十名，每二年一贡（向国子监贡送一人），是蔚州士人入仕的重要途径。
- **文蔚书院八景**：靳荣藩题文蔚书院八景图诗，包括"两池草色""一桥月""池畔古柳""池上名花""秋晓陟高楼""花柳池桥一望收""遥指南山""三径客来游"等，以书院园林入诗，寄望"地灵人杰载方册"。
- **考棚**：即考场号舍，为岁科试时生童考试之所。蔚州考棚后改为会文义塾，是书院与考场功能转换的实例。
- **旦字号**：清代乡试以字号分省编卷，宣化府属州县编为"旦字号"。蔚州乡试额中从三名增至四名，与行政区划调整（雍正十二年添入蔚州）直接相关。
