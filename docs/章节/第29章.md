# 第29章 大事记

> 据光绪《蔚州志》第29章（校勘 + 译文 + 学术解读）。完整校勘、影印对照与全集见公众号「蔚县人的那些事」，搜「蔚州旧事」。

### 蔚州志卷十八·大事记（现代汉语译文）

本节为光绪《蔚州志》卷十八《大事记》原文的逐段翻译。原文按年代顺序辑录了自战国赵悼襄王五年（前240）至清同治十一年（1872）两千余年间与蔚州相关的重大历史事件。

**战国至秦代**：赵悼襄王五年，代地发生大地震，这是蔚州地区最早的地震记录。秦始皇十九年，赵国宗室公子嘉率领宗族数百人投奔代地，自立为代王。赵国的亡大夫们渐渐归附他，与燕国合兵，驻守上谷。秦始皇二十五年，秦将王贲灭燕后回师攻代，俘虏代王嘉，代地正式纳入秦朝版图。

**楚汉之际**：项羽将赵王歇迁封于代。陈馀收复赵地，迎赵王歇于代，恢复其赵王之位。赵王感激陈馀，封他为代王。陈馀因为赵王势弱，国家初定，留在赵王身边辅佐，而派夏说以相国身份镇守代地。

**西汉**：汉王三年冬十月，韩信、张耳东下井陉击赵。汉王给兵三万人，遣张耳一同进军，击破赵代，在阏与擒获代相夏说。斩陈馀，获赵王歇，设置常山、代郡。汉五年秋七月，燕王臧荼反叛，攻下代地。高祖亲自率军击之，擒获臧荼。立卢绾为燕王，派丞相樊哙率兵攻代。汉六年正月壬子，以云中、雁门、代郡五十三县，封兄宜信侯喜为代王。汉七年，汉军追击匈奴，闻冒顿居代谷，高祖驻晋阳，派人侦察，回报"可以攻击"。匈奴隐藏精壮兵马，只示人以老弱残兵，使者十批来，都说容易击破。主父偃的谏书可证高祖北至代谷，遭遇平城之围。十二月，匈奴攻代王，代王喜弃国逃归洛阳，赦为合阳侯。立子如意为代王。

汉十一年九月，代相国陈豨反叛。高祖说："陈豨曾为我出使，很有信用。代地是我所急务之地，所以封他以相国守代。现在竟与王黄等劫掠代地吏民，并非百姓有罪。能脱离陈豨、王黄来归者，一律免罪。"高祖亲自击陈豨，破之。下诏调整代地行政区划，将代地常山以南的太原之地划归代国，代国云中以西设为云中郡，使代地所受边寇减少。汉十二年，周勃平定代地，在当城斩陈豨。樊哙在横谷（在蔚州）击胡骑，斩将军赵旣，虏代丞相冯、守孙奋、大将王黄等，与诸将共定代乡七十三。

文帝后六年冬，匈奴三万骑入云中，以中大夫令勉为车骑将军，驻军飞狐。景帝元年，匈奴入代，约和亲。武帝元光六年夏，蝗灾大旱，驃骑将军公孙敖出代击匈奴，亡卒七千人。元狩四年，霍去病率五万骑出代，与匈奴左贤王战，斩首七万余级。元封三年，代郡旱。

**东汉**：更始年间，征代郡太守赵永。耿弇之父耿况为上谷太守，劝赵永不应征召，令其去见光武帝。光武遣赵永复任，赵永北归途中，代令张晔据城反叛，招迎匈奴、乌桓为援。光武帝以耿弇之弟耿舒为复胡将军，击破张晔，赵永才得复郡。

建武十三年，卢芳与匈奴、乌桓连兵侵扰，边境愁苦。诏令王霸率弛刑徒六千余人，与杜茂修治飞狐道，堆石布土，筑起亭障，自代至平城三百余里。建武十五年，迁徙雁门、代郡、上谷三郡吏民六万余口，置于常山关、居庸关以东。建武二十六年，南单于奉表归附，上谷、代诸郡民归于本土。当时城郭已成废墟，重新修建，光武帝后悔当初的迁徙。

建安二十三年，鄢陵侯曹彰讨伐代郡乌桓。曹彰用田豫计，固守要隘。军在易水之北，敌伏骑突袭，军阵扰乱。田豫利用地形，结圆阵，弓弩持满于内，以疑兵堵塞缺口。敌散退，曹彰追击，乘胜逐北，追到桑乾，距代二百里。长史诸将都认为远行疲惫，又受节制不得过代，不宜深入。曹彰说："率师而行，只看有利所在，何论节制？敌人逃不远，追之必破。从令而纵敌，非良将。"于是上马，令军中"后出者斩！"一日一夜追及，大破敌军。

**魏晋十六国**：永嘉之乱后，代北成为各民族政权角逐之地。晋永嘉六年，拓跋猗卢派弟子郁律助刘琨击败白部大人，又攻铁弗刘武。晋封猗卢为大单于、代公。因封邑距本国遥远，向刘琨求句注陉北之地。刘琨遂徙马邑、阴馆、楼烦、繁峙、崞五县之民于陉南，将该地尽献猗卢，东接代郡，西连西河、朔方。建兴三年，进猗卢为代王，置官属，食代、常山二郡。此后代地先后归属后赵石氏、前燕慕容氏、前秦苻氏。太元十三年，慕容永废代，将代地民众全部迁往龙城。

**北魏**：天兴元年正月，发卒万人修治直道，自望道铁关凿恒岭，至代五百余里。六月定国号魏，七月迁都平城，始即帝位。太和三年二月，太皇太后冯氏与孝文帝巡幸代郡温泉，问民疾苦，将宫女赐给鳏寡者为妻。孝昌元年八月，柔元镇人杜洛周在上谷率众起兵，攻没郡县，南围燕州。自此古代属灵邱，置蔚州，代之名遂消失。

**隋唐**：隋开皇十九年，突厥雍虞闾与玷厥举兵攻染干，尽杀其兄弟子侄，渡河入蔚州。唐代蔚州地位日益重要。武德五年蔚州总管高开道反唐。宏道元年突厥骨笃禄寇蔚州，杀刺史李思俭。开元六年移横野军于蔚州山北，屯兵三万。元和中王锷在蔚州三河冶设炉铸钱，利用拒马河水力，每年铸钱一万八千贯，解决了河东地区钱荒。会昌二年蔚州刺史契苾通率蕃兵击回纥，李商隐有诗赠之。乾符以后，沙陀李克用势力在蔚州崛起，北据蔚朔，南侵忻代。

**辽金**：会同元年，后晋遣赵莹以燕云十六州并图籍献契丹，蔚州升忠顺军节度使。统和四年辽军在蔚州大败宋军，耶律斜轸、耶律题子等名将显赫一时。金天辅六年蔚州降金，天会七年首次在蔚州开设科举考试，孙九鼎为魁首。大定年间金世宗因蔚州采地蕈扰民而下诏训诫。金末蒙古军队进入蔚州。

**元代**：至大元年升蔚州为蔚昌府。至正十九年杨诚据蔚州，元军反复征讨，至二十年始平。

**明代**：洪武二年都督张温取蔚州，元臣楚宝善以城降。建文二年燕王朱棣在靖难之役中攻取蔚州。正统十四年土木之变后，明英宗被俘北行，途经蔚州。终明一代，蔚州是抵御蒙古俺答、小王子的边防重镇。嘉靖年间俺答数次深入蔚州、广昌，杀掠惨重。万历九年蔚州大地震，城垣大坏。天启二年蔚州爆发妖人侯德之乱，被知州李宣猷平定。

**清代**：康熙三十二年改蔚州卫为蔚县，雍正六年蔚州改属直隶宣化府，乾隆二十二年并蔚县入蔚州。有清一代大事记载以自然灾害为主，大旱、大疫、蝗灾、地震、水灾频发，官府多次发仓振济。

### 译注

1. **弛刑徒**：解除枷锁的刑徒，汉代用于修筑边防工程的一种劳役形式。
2. **飞狐道**：又称飞狐陉，太行八陉之一，位于今蔚县与涞源县之间，自古为华北平原通往代北的咽喉要道。
3. **代谷**：汉代地名，在今大同盆地一带，为匈奴冒顿单于驻牧之地。平城之围即发生于此。
4. **三河冶**：唐代在蔚州飞狐县（今涞源）设立的官营冶铁铸钱工场，利用拒马河水力驱动。
5. **契苾通**：铁勒契苾部人，唐蔚州刺史，会昌年间率蕃兵参与唐军对回纥的军事行动。李商隐有《赠别前蔚州契苾使君》诗。
6. **忠顺军节度使**：辽代在蔚州设置的节度使级军镇，为辽控扼宋边境的重要军事建制。
7. **暖泉**：蔚州著名泉池，位于城西，冬季水气蒸腾如雾，明代以来为蔚州名胜。
8. **蔚昌府**：元武宗至大元年蔚州升格为府，属中书省大同路，不久复为州。
9. **顺圣川**：即今河北阳原县境内桑乾河谷地，明代为宣府镇辖地，蔚州西北交通要道。
10. **交牙山**：蔚州境内山名，金天会十三年征发民夫四十万人在此采木造战船，欲由海道攻宋。
11. **木瓜涧**：蔚州境内地名，唐乾宁四年李克用在此遭伏兵大败。
12. **达靼**：即鞑靼，北方游牧民族，唐末李克用曾避难于达靼部。

## 三、学术解读

### 史源与编纂

《蔚州志》卷十八《大事记》属光绪《蔚州志》之编年部分。编纂者广泛辑录《史记》《汉书》《后汉书》《三国志》《晋书》《魏书》《北史》《隋书》《旧唐书》《新唐书》《旧五代史》《新五代史》《辽史》《金史》《元史》《明史》等正史本纪、列传、志书中的相关记载，兼采《资治通鉴》《水经注》《方舆纪要》《元和郡县志》《宣府镇志》等史地典籍，以及府志、旧志、志补、州册等地方文献。

编纂方法仿正史本纪体，以年月为纲，逐条系事，附注出处。对于史料有歧异之处（如"代谷"地名辨正、李克用在蔚州事迹年月排比等），均出按语辨析，体现了清代方志考证之学的特点。尤其值得注意的是，编纂者在代地沿革考证中，辨析顾炎武仅知代有三迁、阎若璩言七迁之疏漏，以八迁正之，可视为一篇独立的代地历史地理考证短文，反映了编纂者深厚的史学功底。

### 制度史解读：蔚州军政地位的演变

从大事记可清晰梳理蔚州军政地位的演变轨迹：

1. **先秦至汉代**：以"代"之名行世。战国为代地，秦置代郡。汉代为代国、代郡交替，是汉匈冲突的前线，飞狐道为重要军事通道。高祖平城之围、文帝军飞狐、武帝四将军出代，皆以代地为汉匈交锋之核心区域。
2. **北魏至隋唐**：孝昌中始置蔚州。唐代蔚州为河北道、河东道边州，设总管府、横野军，兼具边防与铸钱（三河冶）双重功能。元和年间三河冶铸钱每年达一万八千贯，是唐代重要的官营铸钱工场。
3. **辽金**：蔚州升为忠顺军节度使，属辽南京道。金代延续其建制，并成为科举考试的考场之一。天会七年首试举人于蔚州，反映了金朝对燕云地区的文教经营。
4. **元明**：元代短暂升蔚昌府。明代蔚州属大同府，为九边重镇之一。洪武二年筑城，城高三丈五尺，号称"铁城"。嘉靖年间俺答连年入犯，蔚州始终未被攻破，"铁城"之名益彰。
5. **清代**：改卫设县，雍正六年改属直隶宣化府。乾隆二十二年县并入州，军政地位有所下降，大事记载转为以自然灾害为主。

### 社会经济史解读

大事记中灾害与赈济的记载尤多，透过这些记载可窥蔚州传统农业经济的脆弱性：旱、蝗、雹、震、疫交替出现，平均数年即有一次严重灾荒。官府应对措施包括开仓振恤、发帑筑堤、设粥厂等。乾隆五十二年诏令"先行赏给贫民两月口粮"，尤可见清廷救灾体系之运作。道光十二年知州康锡新倡捐米九百九十四石，分设粥厂，自十二月至次年四月止，是清代地方官赈灾的典型实例。

明代正德九年宣府巡抚丛兰置毒田间以杀敌的计策，从侧面反映了蔚州军民在边患与自然灾荒双重压力下的生存智慧。金天会十三年征发燕云两路民夫四十万人在蔚州交牙山采木造战船，因百姓困苦、蜂起反抗而中辍，是金代重大工程失败案例，也是研究金代役法与民众反抗的重要史料。

### 民族与边防史解读

蔚州地处农耕与游牧交界地带，大事记集中反映了长时段民族关系史。从汉匈对峙、北魏代北建国，到唐代突厥回纥、辽宋对峙、金元更替，再到明代蒙古俺答、小王子连年入犯，蔚州始终处于民族冲突与交融的前沿。明中期（嘉靖朝）是边防压力最大的时期，俺答多次"薄蔚广，杀掠惨毒"。隆庆五年俺答封贡后，边境才趋于缓和。大事记中"铁城"之名的流传，正是蔚州作为边防堡垒的历史记忆。

## 四、背景知识

### 历史地理背景

**代地沿革考**：据编纂者考证，"代"之地名经历了八次迁徙——王喜都古代、汉文都晋阳、汉文又都中都、卢芳居高柳、猗卢都盛乐、道武帝都云中、道武帝又都平城、后周宇文达国上党。至于"代郡"，西汉治桑乾、东汉治高柳、晋治古代、后魏治平城、隋初治马邑。五代以后，"代"之名称北移于雁门（即今代县），而蔚州承继了古代地区的核心地域。顾炎武仅知三迁，阎若璩言七迁，编纂者以八迁正之。

**飞狐道**：太行八陉之一，位于蔚州东南，是连接华北平原与山西高原的要道。东汉建武十三年王霸治飞狐道，"堆石布土，筑起亭障"，此后历代均为重要军事通道。辽穆宗曾以"飞狐道狭"而诏耶律敌禄广之。

**暖泉**：蔚州城西之名泉，水温四季恒定，池中生翰藻。万历二十八年（1600）暖泉池翰藻盛放，"形如车轮，叶如翠羽"，被视为文运昌盛的祥瑞之兆。

### 制度背景

**明代的"铁城"**：蔚州城始建于北周，明代洪武五年德庆侯廖允中辟土为城，洪武七年指挥周房"因旧址筑城"，城高三丈五尺、周长七里，包以砖石，极为坚致。嘉靖庚戌之变（1550）中蔚州未被俺答攻破，"铁城"之名遂传诵边塞，成为蔚州最具特色的文化符号。

### 人物背景

- **李克用**（856-908）：沙陀人，唐末在蔚州一带起家，官至河东节度使，封晋王。其子李存勖建立后唐，追尊李克用为武皇帝。乾宁四年李克用 drunken state 导致木瓜涧之败，是五代史中的著名战例。
- **契苾通**：唐代铁勒族将领，会昌年间任蔚州刺史，率蕃兵参与对回纥的军事行动。李商隐有《赠别前蔚州契苾使君》诗赞誉其家风与战功。
- **李宣猷**：明天启年间蔚州知州，涞水妖人侯德在蔚州聚众谋乱，宣猷设计擒之，保全一城。
- **耶律斜轸**：辽代名将，统和四年宋辽战争中，率军收复蔚州，斩首三万余级，并在飞狐口设伏大败宋军，是辽宋蔚州之战的关键人物。

### 知识卡片

1. **平城之围**（前200）：汉高祖刘邦在代谷被匈奴冒顿单于围困于平城白登山七日，后用陈平计得脱。此役直接促成西汉与匈奴的和亲政策，蔚州所在代地是事件发生的关键区域。

2. **燕云十六州**：936年后晋石敬瑭割让给契丹的十六州，蔚州为其一。北宋始终未能收复，直至1368年徐达北伐才重归中原王朝。会同元年辽朝以蔚州升忠顺军节度使，确立了蔚州在辽代军政体系中的地位。

3. **三河冶铸钱**：唐元和七年（812），河东节度使王锷在蔚州三河冶置炉铸钱，利用拒马河水利，每岁铸钱一万八千贯，解决了河东地区长期使用铁钱的不便，是中国冶金史上的重要案例。

4. **蔚州交牙山采木**：金天会十三年（1135），征发燕云两路民夫四十万人在蔚州交牙山采木，由唐河及人工河道运至雄州造战船，欲自海道攻宋。因百姓困苦、蜂起反抗而中辍，是金代重大工程失败案例。

5. **代有八迁**：据编纂者考证，代国国都前后凡八迁——王喜都古代、汉文都晋阳、汉文又都中都、卢芳居高柳、猗卢都盛乐、道武帝都云中、道武帝又都平城、后周宇文达国上党。顾炎武仅知三迁，阎若璩言七迁，编纂者以八迁正之。

6. **木瓜涧之战**：唐乾宁四年（897），李克用率五万兵攻刘仁恭，师次蔚州。因大雾不辨人物，幽州将杨师侃伏兵于木瓜涧，河东兵大败失亡大半。克用醉酒临阵，醒而后知败，为五代著名战例。

7. **天启星陨**：明天启二年（1622）十一月，蔚州天鼓鸣，星陨于理刑署库。陨星"形甚皱，非石非铁，气如硫磺，权之可重五斤"，是中国古代陨石记录中描述较为详细的一条。
