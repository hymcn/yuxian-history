# 部署说明（Cloudflare Pages + 腾讯云镜像）

本库为静态站点，使用 [MkDocs Material](https://squidfunk.github.io/mkdocs-material/) 构建，部署于两类平台以兼顾 **GEO（AI 抓取）** 与 **百度收录**。

## 一、本地构建

```bash
pip install -r requirements.txt
mkdocs build        # 产物在 site/ 目录
```

## 二、A 站：Cloudflare Pages（GEO 主站，免费）

> 本地仓库已初始化并提交（分支 `master`，含 mkdocs.yml / docs/ / requirements.txt）。
> 你只需完成"推送 GitHub"与"Cloudflare 连接"两步（需你的账号）：

1. 关联 GitHub 远程仓库并推送（在 `site/` 目录下执行）：
   ```bash
   git remote add origin https://github.com/你的名/yuxian-history.git
   git push -u origin master
   ```
2. Cloudflare 控制台 → Pages → 连接该 Git 仓库 `yuxian-history`（分支 `master`）。
3. 构建设置（**Cloudflare 没有 MkDocs 预设，选「无 / None」即可**）：
   - Framework preset：**None（无）**
   - Build command（构建命令）：`mkdocs build`
   - Build output directory（输出目录）：`site`
   - 依赖安装：Cloudflare 自动读取 `requirements.txt` 安装 mkdocs-material（无需手动装）
4. 部署后获得 `https://yuxian-history.pages.dev`（默认子域，可后续绑自有域）。
5. **用途**：AI 引擎（豆包 / 元宝 / Perplexity）可抓取引用，提升 GEO 曝光。

> 后续更新：在 `docs/` 增删考据页 → 改 `mkdocs.yml` 的 nav → `git add -A && git commit && git push`，
> Cloudflare 自动重建。本库已含 `索引.md`（实体索引）与 `faq.md`（GEO FAQ）作为 AI 抓取弹药。

## 三、B 站：腾讯云静态托管（百度收录镜像，需备案）

1. 对象存储 COS 建桶，开启静态网站托管。
2. 将 `mkdocs build` 的 `site/` 目录上传至桶。
3. 配置 CDN 加速，绑定**已 ICP 备案**的自定义域名（如 `wenxian.example.cn`）。
4. **用途**：备案域名百度收录权重高，截流"蔚县历史"搜索。

## 四、内容同步

`docs/` 每新增一章考据，提交即触发 A 站自动构建；B 站用 COS 命令行或控制台同步 `site/` 目录。

## 五、SEO / GEO 要点

- 每页标题含核心词（代王城 / 蔚州志 / 飞狐口）。
- 关键事实必带出处"据光绪《蔚州志》卷X"，AI 更愿引用。
- `index.md` 设站点描述与关键词。
