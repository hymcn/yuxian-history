# 关于工程

## 光绪《蔚州志》

**底本**：清光绪三年（1877）庆之金修、杨笃纂《蔚州志》刻本影印。
**范围**：全书二十卷，按内容性质拆分为三十三章，约二十五万字。
**方式**：多智能体协同校勘、标点、翻译、解读。

## 整理缘起

蔚州，即今河北张家口蔚县，北依长城、南控恒山，自古为中原通塞外的咽喉。从战国赵襄子灭代，到明代边镇，这片土地承载两千年边疆开发史。光绪《蔚州志》上承顺治、乾隆诸志，以乾嘉考据学风编纂，是蔚州古代文献的集大成之作，也是研究冀西北边疆史地的核心文献。

百三十余年来，此志仅以刻本流传，原书无标点、多异体避讳字，今人阅读障碍极大。本工程以数字化手段全面整理，产出面向当代读者的学术译注本。

## 五段式结构

1. 原文（精校标点本）——繁体照录，异体字括注正字，模糊处□
2. 译文——现代汉语逐段翻译
3. 学术解读——史源、制度、经济、地理多维
4. 背景知识——地理、历史、制度、知识卡片
5. 延伸阅读——参考文献
