# 乾隆

> 本版本为规划中的待数字化志书。光绪《蔚州志》即于顺治、乾隆诸旧志基础上重纂（据光绪《蔚州志》卷首序）。

## 现状

- 顺治《蔚州志》：顺治末年知州李英纂修，为蔚州首部系统方志。
- 乾隆《蔚县志》：乾隆初年修。
- 乾隆《蔚州志補》：乾隆九年（1744）知州杨世昌修，补顺治、乾隆初两志之未备。
