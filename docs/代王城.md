# 代王城

> 蔚州城东二十里许的先秦都城遗址，河北保存最完整的汉代郡级城址。
> 史料出处：光绪《蔚州志》卷三·地理志上、卷五·地理志下；尹耕《两镇三关志》

蔚州城东二十里许，有一片周回二十五里的故墟，当地人称**代王城**。光绪《蔚州志》记得分明："俗呼代王城，周回二十五里，九门遗址俱在。"今天站在城垣下，仍能辨出九座城门的夯土遗迹。

## 一、从代国到代郡

代，是春秋末年的诸侯国。赵襄子设计诱杀代王，并其地，《史记》谓"赵襄子北登夏屋，诱代王，以金斗击杀之"。代王夫人乃赵襄子之姊，闻变磨笄自刺而死，后世名其山曰**磨笄山**。这一"和亲—灭国"的掌故，是蔚州作为边地要冲最早的一页。

入汉，这里为**代郡**治所。高帝六年封兄刘喜为代王，七年为匈奴所攻，弃国自归；文帝时改封代王，即后来的汉景帝一系。代郡领县十八，郡治屡迁桑乾、高柳，而"代"之名始终系于此城。

## 二、志书里的两处考辨

清代方志学家尹耕作《代国考》《代郡考》，于先秦两汉代地沿革最为精核。光绪《蔚州志》总纂杨笃又据《水经注》道里，纠正旧志一处明显错误：府志、志补因郦道元"连书"邻郡，竟在"故城"上添一"代"字，谓昌平郡亦在蔚境；杨笃考定昌平郡去代王城六十里、在东北一百一十里，实当今宣化地，"安得增易原文，强相附会"。

城外数里小山名**擂鼓堝**，相传代王喜与燕王卢绾相约，有急击鼓相闻。然此事于正史无考，志书谨"存其说以备参考"——这般"有疑必注"的态度，正是乾嘉考据的筋骨。

## 三、金波泉与城中之水

代王城水脉亦盛。金波泉发源于城内，向东北流；城南又有密河，西北流入壶流河；城东门转泉，经水北村入河。现代考古调查证实，遗址范围内确有多处泉眼出露，与文献若合符节。

## 校勘记

1. **"嘔夷"**：即祁夷水（今壶流河上源），详见山川篇。
2. **"雊瞀"**：读 gòu mào，汉上谷郡县，在今桃花堡北。
3. **"擂鼓堝"**：正史无考，存疑。

## 译注

- **代王城**：汉代代郡都城，蔚州城东二十里，周二十五里，九门遗址尚存，河北保存最完整汉代城址。
- **磨笄山**：代夫人磨笄自刺处，在代城东南二十里，体现传统节义观念。
